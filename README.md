# Scoop bucket for MangaBinder

[Scoop](https://scoop.sh) bucket for [MangaBinder](https://github.com/Preygle/manga-downloader):
download manga chapters, convert them to PDF, bind them into volumes and export CBZ.

```powershell
scoop bucket add preygle https://github.com/Preygle/scoop-bucket
scoop install mangabinder
mangabinder            # opens the browser interface
```

Update with `scoop update mangabinder`. The manifest follows new
[releases](https://github.com/Preygle/manga-downloader/releases) automatically.
